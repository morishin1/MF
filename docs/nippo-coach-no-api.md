# 日報コーチ：API不要の手動相談（2026-10-22）

## 目的
社員がGWの日報と翌営業日の業務予定を見ながら、ChatGPT / Claudeアプリに自分で相談できるようにする。AI APIを追加契約せず、既存のSlack窓口を改修しない。

## UI / 操作
1. `/nippo.html` → 「今週の業務予定」 → 「振り返りをAIに相談（コピー）」。
2. 「AI相談文の確認・編集」欄に、今日の成果（完了・未完了と理由）、今日の優先事項、翌営業日の優先事項・現在表示中の翌営業日の予定が出る。
3. **本人が必ず確認し、顧客名・個人情報・機密内容を削除してから**「確認した内容をコピー」を押す。
4. ChatGPT / Claudeアプリ等に人が手動で貼り付ける。得られた助言を読んでから、自分で日報・予定へ反映する。
5. 予定確認画面で別の日を選択している場合、その別日の予定を「翌営業日の予定」としてコピーしない。

## 境界・運用ルール
- 新規実装 `js/nippo-coach-copy.js` はブラウザ内で文字列を組み立て、明示ボタンでクリップボードにコピーするだけ。**fetch / AI API / Supabase / 自動Slack送信 / 新規SQL / 新規cronはない**。
- 今日の実績は本人入力であり、独立して検証された成果とはみなさない。予定は実績と扱わず、勤務日・休暇は断定しない。
- 人事評価・懲戒には使わず、「よかった行動」「次勤務日で改善する行動を1つ」「次回の振り返り」の3点だけを依頼する。
- 「困ったこと」（管理者限定の相談内容）・給与・社員名・メールアドレスなどを意図的に収集しない。ただし本人が仕事の入力欄へ秘密を書いた場合には文章へ現れ得るため、確認欄を出して削除可能にしている。
- **既存の**「翌営業日のAIチェック」「今日のAIフィードバック」等には変更を加えない。既存のAI API利用の有無・料金はこれとは別の問題。
- 日報の保存、提出条件、翌営業日ゲート、既存のナレッジ、管理者の閲覧権限は変更しない。
- 既存のPR #167（DB148・AIコーチ草案/承認）はDraftのまま**別管理**し、この軽量PRのマージ条件にしない。
- PR #159（Slack秘書）・SQL147は保留のままとする。
