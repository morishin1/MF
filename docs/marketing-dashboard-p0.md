## 表示の決まり

| 場面 | 出し方 |
|---|---|
| 計測していない数字 | `—` と「未計測」。0件・増減率・達成率は出さない |
| サイトの公開設定日がある | 「公開設定 YYYY/MM/DD」＋状態「確認待ち」（実反映は未照合。行を開くと「直近30日の記録」と出す） |
| 取得できたが直近30日に記録なし | 「直近30日：公開記録なし」＋「取得済み」（それより前の更新が無いという意味ではない） |
| 権限なし／未準備／取得失敗／未接続／保留 | それぞれの文字で出す（色は 灰／黄／赤／灰／灰） |
| 今週やること | 計測が未接続なので「設定に必要なこと」として3件（件数・期限は作らない） |

## 操作

- 期間（7／30／90日）・事業（すべて／自社サイト／無限道場／EIGHT SPACE。EC は保留中で選べない）は URL（`days`・`biz`）に残る。
  再読込・ほかの画面から戻っても消えない。事業は詳細の一覧の絞り込みと共通
- KPI を押すと根拠を開く：発信数 → 制作予定の一覧（公開済み）、有効問い合わせ → 問い合わせの一覧（同じ事業）、ほか → 計測の接続状況
- 詳細の一覧は URL に `tab` があるときだけ開く（期間・事業だけでは開かない）
- 開く・絞り込む・行き来するだけでは何も書かない（テストで確認）
