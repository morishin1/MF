## どちらが正か

同意の対象になる本文は **`lib/consent-docs.js`** です。画面の「全文を読む」も、
同意時に保存される全文も、そこから出ます。この Word は配布・掲示用の原本です。

本文を直すときは、`lib/consent-docs.js` を直して `version` を上げ、
この Word も同じ内容に合わせてください。
内容が実質的に変わる改定は `major: true` にすると、以前の版に同意していた人にも
読み直して再同意してもらう流れになります。

## 労働条件通知書・雇用契約について

この3つとは別の流れ（`gw_contracts`）で扱います。
「読みました。内容に同意します」方式には一律変更していません。
