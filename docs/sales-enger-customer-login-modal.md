# 企業ログイン・商談モーダル（ENGER for Business）

## 2種類の認証を混同しない
- 社内Salesのログインは `gw.8grp.co.jp/sales`。
- 企業用のログインは `enger.jp/business/login`。企業の公開候補は法人ログイン後だけ表示。
- 以前にMF専用の `gw_company_portal_access` へ登録した社内テスト利用者では、ENGERの `dx2_company_portal_members` に登録されていないためログインできない。
- 企業側で新規登録を行う必要はない。Salesの営業責任者が商談モーダルから初回発行する。

## 商談ボタンからの運用
1. Sales企業一覧で企業を選択。AIおすすめまたはENGER登録候補から公開する人材・案件を選び「商談」を押す。
2. モーダルに企業ID、担当者メール、企業ログインURL、アカウント状態を表示。
3. 未発行なら営業責任者・管理者が相手企業の担当者名・メールを入れ、確認後に「ログインID・一時パスワードを発行」。
4. 発行した**一時パスワードは画面に1度だけ表示**しコピー可能。2分後、商談モーダルを閉じた時に消去。DBやSalesに平文保存しない。
5. 既存パスワードは再表示不可。本人が忘れた場合のみ確認を取って再発行すると、以前のものは無効になる。
6. 一時パスワードを本人に安全な経路で伝える。企業はID（担当者が1名の場合）または担当者メールとパスワードでENGERへログイン。
7. 商談の5ステップ画面へ進み、Sales側の進行を企業側へ同期。企業は自社の公開承認済み候補のみ閲覧できる。

## プレビューと本番
- `ENGER_PORTAL_BASE_URL` はMFプレビューの対象Gitブランチにだけ設定可能。本番は `https://enger.jp` のまま。
- ENGER商談のセッションIDはログインURLの `next` に含め、ENGERのログイン画面でUUID・同一オリジンを検証する。パスワードはURLに絶対含めない。
- ENGER法人アカウントが未発行の場合、営業担当が商談画面を開けても企業は参加できない。認証を代行せず、担当者にログインしてもらう。
- 実アカウント発行・ログイン済みE2E・企業境界確認が終わるまでは本番マージしない。
