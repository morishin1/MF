# 本番E2E：採用決定 → 契約 → 入社 → キャリア → 3か月育成（PR #27）

テスト専用のデータ1名で行う。既存の顧客・社員のデータには触らない。

## 準備（テスト専用データ）

| 項目 | 値 |
|---|---|
| 応募者名 | `E2Eテスト 太郎`（名前の先頭に必ず `E2Eテスト` を付ける） |
| メール | 自分が受け取れるエイリアス（例：`自分+e2e-hr@…`） |
| 入社予定日 | **30日以上先**（入社日が来て自動で在籍になるのを避ける） |
| 担当・上長 | 自分 |

- 操作する人：管理者A（owner）＝自分のアカウント
- 本人役：上のエイリアスで作った本人アカウント（別ブラウザかシークレットウィンドウ）
- 事前に Supabase で `db/095_career_meeting.sql` を適用し、末尾の確認SQLが通ること

各ステップで、次の2か所の **現在状態 / NEXT ACTION / 担当** が表のとおりになるかを見る。
- 管理画面：`評価・キャリア ＞ 入社〜育成`（`/admin-career.html?tab=journey`）の行と、右ドロワー
- 本人画面：本人のホームに出る NEXT ACTION

- 右ドロワーの上部の進み具合（採用決定／契約／入社／キャリア／育成／評価）の「いま」が動く。
- Primary CTA は常に1つ。
- 保存したあともドロワーが閉じない。

## 契約前の人が通常社員として扱われないこと（手順 2〜5 のあいだ）

- 本人のメニューが「ホーム・やること・入社手続き・契約書・マイページ」だけで、勤怠・日報・申請・経費が出ないこと
- メンバー管理で、本人の状態が「入社準備」（invited）のままであること
- （任意）本人の端末から `/api/timecard/me` を POST すると 403 `not_joined` が返ること
