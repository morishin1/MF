# HR Word雛形・契約書自動発行 — 原本照合と受入条件
更新日: 2026-11-15 / PR #358（#357を先に統合する）

## 目的と前提
既存の人事データから、利用者が確認した正式なWord雛形に値を差し込み、原本の表・書式・条項を保ったDOCXとPDFを発行する。
本資料は個人名・個別の雇用条件を含まないレビュー用メモ。共有済みの実際の「有期雇用契約社員・試用期間用」の原本を**文章の自動修正・本番投入をせずに**項目照合した結果に基づく。元ファイル自体はGitHubへ置かない。

## 1. 現行HRで直接取得できる項目
- 応募者: 氏名、住所（本人情報に未登録なら空欄）
- 採用条件: 契約開始日 `joinDate`、終了日 `contractEndDate`、雇用形態 `employmentType`、職種 `jobTitle`、勤務地 `workLocation`
- 雇用条件: 週所定労働時間 `weeklyHours`、試用期間 `probationMonths`
- 給与（権限必須）: 賃金形態 `wageType`、賃金額 `wageAmount`
- 追加条件 `offerTerms`: `duties`、`workHours`、`breakTime`、`holidays`、`overtime`、`wagePayment`、`commuteCost`、`allowances`、`dutiesChange`、`workLocationChange`
- 会社情報: 会社名、所在地、代表者名（会社の確定済み基本情報からのみ）

## 2. 原本との主要な差分（自動埋め込み禁止の項目）
正式な原本には、総支給額に加えて「基本給」「固定残業代」「固定残業の対象時間」「超過分の割増賃金」の記載がある。
現行HRの単一 `wageAmount` のみでは内訳を復元できないため、**差額計算や原本の数字の流用を禁止する**。次の項目は採用条件入力画面で人事権限者が確認・明示入力し、合計整合を検証する仕組みが必要:
- 基本給（月額）
- 固定残業代（月額）
- 固定残業の対象時間
- 超過分割増の取り扱い（原本条項の確認）
- 通勤費の上限やその他手当（設定する場合のみ）
- 契約更新条件、社会保険、休日・休暇、労働時間と休憩時間のうち原本ごとの可変部分

`wageAmount` を基本給や固定残業代とみなさない。必要項目が未入力なら `missing` を返し、発行しない。既存資料にある個人別の金額を他の人の初期値にはしない。

## 3. 法務・労務レビュー必須
原本には、一定期間の無返信・未署名を契約への同意と取り扱う趣旨の条項が含まれる。正式な電子契約や本人の明示的な承諾と整合するか、**社労士または弁護士の確認前に、この条項を有効なものとして扱わない**。
同様に、契約更新・労働条件の変更・固定残業代の適法性は、発行者による確認を必要とする。
システムのステータスは **下書き → PDFプレビュー → 人事・専門家レビュー → 確定 → 本人への送信 → 明示的な合意 → Office引継ぎ** を分離する。
「未返信」「開封」「送信済み」を「合意」に自動変換しない。

## 4. 受入テスト
1. 原本（個人名・固定金額などを置換して匿名化した雛形）に許可された `{{項目名}}` のみ含むことを登録時に検査する
2. Wordの段落・表・フッター・改ページ・太字などが変わらず、差し込んだ文字列だけが変わることを確認する
3. 未入力・別応募者ID・破損DOCX・不正な日付・逆転した契約期間・不正な給与形式を拒否する
4. Google Drive一時変換後に一時ファイルを削除できなければ失敗にする。原本PDFとのページ割付と日本語文字を目視比較する
5. 人事権限と給与権限、テナント分離、版の不変性、同一発行の重複防止、監査記録を統合テストで検証する
6. 送信・合意・正式なOffice引継ぎは、独立した明示操作なしには実行されない
7. 実応募者データを用いたプレビューテストや本番メール送信は行わない

## 5. 実装順
1. #357を最終CI・実権限で確認してmainへ取り込む（#356は重複取込しない）
2. #358を最新mainに追従させ、採用条件の不足項目と権限付きAPIを実装する
3. 原本の匿名化・雛形登録・DOCX出力・PDF変換・プレビューを検証する
4. 人事・社労士レビュー後に確定ボタンを公開。送信・合意連携は独立リリース判定
5. migration適用、本番デプロイ、実在契約書発行は上記受入と承認まで保留

## 非目標
過去に発行した契約書の書き換え、旧Office契約/署名機能の置き換え、応募者の一括更新、本人への自動送信、法的合意の推定。
