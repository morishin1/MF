# HR スポット人材：一覧でチェックして更新・削除（db/146）

## 操作
- 画面 `/hr/spot.html` の一覧の左端にチェックボックス。
- 表示中のすべてを選択／選択解除。対象は最大50件。
- 選択した人材を「長期採用候補」「終了」「削除（一覧から除外）」に一括変更。
- 削除済みフィルターに切り替えると「復元」ができる。
- 個別の氏名・媒体・勤務日・メモは詳細から「基本情報を編集」で修正できる。
- 本人アンケートの回答や評価点数は一括上書きしない。

## 安全装置
- 本当のDELETEをしない。deleted_at / deleted_by を付ける論理削除。
- 削除時はアンケートURLを失効。復元しても以前のURLは再利用不可。
- HRの「選考中」に引き継ぎ済みの人材は削除や状態変更を不可にする。
- 長期採用候補への変更は全件について本人回答、連絡同意、継続希望、社内評価が必須。
- RPCで全件の事前条件を検証し、1件でも不適切なら全件失敗（部分成功なし）。
- 採用HR権限、テナント境界と最大50件制限はAPIとDBで担保。
- 画面側も誤操作確認ダイアログを出す。
- 一括操作の履歴は `gw_activity_log` に件数・対象ID・操作を記録する。

## 適用順序
1. 既存 `db/145_hr_spot_talents.sql` が適用済みか確認する。
2. `db/146_hr_spot_bulk.sql` を実行する。
3. `db/check_146_hr_spot_bulk.sql` で新しい列とRPC権限を確認する。
4. GitHub PRのCI・Previewから実操作テスト、本番反映後も確認。
