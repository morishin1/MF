# HR採用メール新着受付｜一括整理・スポット人材登録（改修 #193）

## 目的
Gmail（`saiyou@8grp.co.jp`）から届くメールを**応募者／スポット人材として確実に登録する**。受付と応募者管理を二重運用しない。メールを開いたことは既読であり、対応完了ではない。

## 画面操作
**単独の新着メール：** メールを開く → 左で件名・差出人・本文を確認 → 右の候補を確定 → 登録先「選考中・業務委託・スポット人材」を選ぶ → 登録ボタン1回 → 成功時に元メールが「登録済み」になり、元の受信履歴から辿れる。同一応募者がすでにいる場合は「既存応募者に紐づける」。同姓同名・同媒体のスポット人材は、既存登録を確認し明示リンクを行う。スポットは氏名・勤務日・媒体・勤務メモを確認して登録し、本人のメールや電話は勝手にコピーしない。

**不要メール：** 新着詳細で「応募者登録しない場合の理由」を選択（営業・広告／システム通知／配信エラー／重複メール／応募対象外／その他）→「対象外にする」。元メールは履歴に保持、未対応件数から外れる。誤操作なら「未対応に戻す」。迷う場合は「確認中」。タイミー等のスポット人材は**対象外にせず**登録先でスポットを選んで登録する。

**一括：** 一覧でメールをチェック → 画面下部のバーで「確認中」「未対応に戻す」「対象外」「削除（復元可）」→ 必要に応じ理由を選択 → 確定。最大50件。登録済みのメールは一括変更/削除できない。別の担当者が途中で更新した場合は全件変更しない。

**削除：** 物理削除ではなく「一覧から除外（論理削除）」。受信記録と操作証跡を保持する。「削除済み（復元可）」のプルダウンから選び、下部の［削除を取り消す］で復元できる。セキュリティ・監査・誤削除防止のため、応募者紐づけ済みの受信メールは削除できない。個人情報の保存期限・完全消去は別の承認/保管ルールによる。

## ステータス
- 新着／確認中：未対応。開いただけでは完了しない。
- 登録済み：通常の応募者またはスポット人材に紐づけ済み。完了扱い。登録先は参照できる。
- 対象外：応募登録しないと判断した記録。理由を保存、未対応に含めない。
- 削除済み：通常一覧・未対応から除外。復元後は対象外に戻し、新着には自動で戻さない。

## 検証
新規合成メール3通（通常応募／タイミー／配信エラー）で、登録、重複検知、対象外、2件一括変更、削除→復元、件数整合を確認する。元メール本文には機密リンクや応募者実情報を使わない。PCと390pxでモーダル・選択バーが隠れないこと、権限のないメンバーに表示されないことも検証する。
