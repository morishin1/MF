# 提案が決まらない企業との改善商談

Salesの「提案管理」から「改善商談の候補」を選ぶ。初期条件は、直近90日に案件側へ送付した提案のうち、送信後14日以上経ったものが3件以上あり、直近90日の送信分に合格も稼働も記録されていない企業。日付や結果が未記録のときは、原因を企業に確認する。

| Salesで見る工程 | 確認する記録 |
| --- | --- |
| マッチング | 案件と人材の紐付け、またはマッチング記録 |
| 提案 | 案件側への送信記録 |
| 所属確認 | 確認依頼、人材側の返答、所属会社に確認した提案可否 |
| 結果 | 案件側の「進める」「見送り」、回答待ち、面談実施 |
| 合否 | 実施した面談の合格・不合格。実施のみ判明した場合は結果待ち |

企業名から各提案、見送り理由、相手の回答を確認する。理由が曖昧なら商談の議題にする。たとえば「スキル不足」と言われた場合は、必須だった工程と経験年数、その判断のもとになった経歴を確認する。「所属確認・見送り根拠」に、どちら側の事情か、誰にいつ確認したか、発言やメールの記載を残す。

「改善商談・取引条件」で商談担当、議題、日時を登録する。商談実施後に企業が挙げた原因、次の提案で変えること、効果を確かめる日を保存する。企業IDがSalesにつながっていると、確定日時と実施記録が営業商談に反映される。画面上で商談後の提案、面談、合格件数を追える。

## 企業の取引条件

| 区分 | 個別提案の取り扱い |
| --- | --- |
| A 重点取引 | 優先して提案 |
| B 通常取引 | 通常の提案 |
| C 条件付き | 管理者が根拠と条件を確定し、案件ごとに相手の回答と有効期限を記録してから提案 |
| D 新規個別提案停止 | 改善商談の実施と、商談後に送った提案を含む2件以上の具体的な案件側の見送りを管理者が確認して適用 |

見直し日に条件を再評価する。区分を変更すると旧条件での案件の承認は失効する。新規個別提案の登録とENGERでの案件側への初回メール準備で条件を照合する。

## 担当別の評価

提案担当の成功は実際の面談実施、クロージング担当の成功は実施面談に対する企業の合格とする。初回の個別送信と、面談実施前の正式な引継ぎに基づいて担当を確定する。案件の再開後はその回の記録を使う。

評価画面には対象数・成功数・外部要因・結果待ち・原因未確認・実績率・調整後の率を表示する。実績率の分母は結果判明件数。調整後の率は確認済みの外部要因と原因未確認を除いて算出する。直近90日で観察期間14日を経過し、同じ役割・サービス・担当時の取引区分・案件難易度で比較する。調整後の母数は提案担当20件以上、クロージング担当10件以上、本人の結果・原因の確認率と役割全体の担当・比較条件の照合率はそれぞれ90%以上を要する。2人以上が条件を満たすと順位を表示し、同率は同順位とする。
