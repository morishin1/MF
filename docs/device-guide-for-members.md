# 端末管理 メンバー向け案内（そのまま読める版）

メンバーに説明するときに使う原稿と手順です。
**画面に出ている文言と、この案内の文言をそろえてあります**（`lib/devices.js` / `api/devices/me.js`）。
片方だけ直すと「聞いた話と画面が違う」が起きるので、どちらかを変えるときは両方直してください。

対象は **ブラウザ側だけ** です。パソコンに入れる会社のソフト（エージェント）は、
実機検証が終わるまで配りません（`docs/device-agent-testing.md`）。
配るときも、入れるのは管理者か社内IT担当です（`docs/device-zero-cost.md`）。

---

## 1. 集まってもらって話すこと（2〜3分）

> これから、社内システムに**どの端末から入っているか**を台帳にします。
>
> 目的は、**会社のパソコン以外から社内の情報が見られていないか**を確かめることです。
> たとえば、退職した人の端末がまだ入れてしまう、私物のスマホから見られている、といったことに
> 気づけるようにするためのものです。
>
> **働きぶりを点数にしたり、評価に使ったりはしません。**
> 深夜や休日の利用を見ているのは、働きすぎに気づくためです。

### 記録すること

- この端末から社内システム（mf）に入ったこと
- その端末の種類（Windows／Mac、ブラウザの名前、画面の大きさ）
- 社内システムを開いていた時間の、1日の合計
- そのうち深夜・休日にあたる時間

### 記録しないこと

- キーボードで打った内容
- パスワード
- メールやチャットの本文
- 画面の録画・スクリーンショット
- 社内システム以外で見たページ
- パソコンに入っているソフト、USBメモリ、ファイル
- パソコンの電源が入っていた時間

> 分かるのは、**mf の画面を開いているあいだのこと**だけです。
> ブラウザを閉じているあいだ、パソコンが何をしていたかは分かりません。

### みなさん側からも見えます

> 自分の記録は、いつでもマイページから見られます。
> **管理者があなたの記録を開いたときは、それもあなたの画面に残ります。**
> 会社から一方的に見るのではなく、お互いに見える形にしてあります。

---

## 2. やってもらうこと（1人1分）

1. **mf にログインする**（いつもどおり）
2. **マイページ** を開く
3. 「**端末の設定・アプリとして入れる**」を押す
4. 出てきた内容を読む
5. 「**このパソコンです**」を押す

**5 を押してもらうことが肝心です。**
端末そのものはログインした時点で台帳に載りますが、
**本人が押すまで、利用時間は1分も数えません**。押さないと「本人の確認待ち」のまま溜まります。

押したあと、同じ画面でできること（任意）:

- 端末に分かりやすい名前を付ける（例:「事務所のノート」）
- 自分が使っている端末の一覧を見る
- 使わなくなった端末を自分で外す
- 管理者がいつ自分の記録を見たかを確かめる

### よく出る質問

| 聞かれること | 答え |
|---|---|
| 私物のスマホで見てもいいの | 会社の決まり次第です。台帳には載りますが、載ること自体が悪いわけではありません |
| 家のパソコンから入ったら怒られる？ | 見慣れない端末として印が付きます。理由が分かっていれば問題ありません |
| 何を見ているか全部分かるの | 分かりません。mf を開いた事実と時間だけです |
| 押さないとどうなる | 「確認待ち」のまま残り、利用時間は数えません。管理者から声がかかります |
| あとからやめられる | 端末を外せます。ただし社内システムを開けば、また載ります |

## 3. 管理者がやること

**システム管理 → 端末管理**（`admin-devices.html`）

| タブ | 見るもの |
|---|---|
| すべて | 台帳の全部 |
| 未通信 | しばらく届いていない端末 |
| 本人の確認待ち | 2 の 5 を押していない人。**ここを毎週ゼロにするのが運用です** |
| ソフト導入済み | エージェントを入れたパソコン（いまは0台） |
| 登録コード | 発行・使用の記録（エージェント用。いまは使いません） |

行を押すと、その端末の記録・アラート・所有者変更・紐付け解除ができます。
**管理者が記録を開いたことは、本人の画面に残ります。** 見る前にそれを承知しておいてください。

### 最初の1〜2週間

1. 全員に 2 をやってもらう
2. 「本人の確認待ち」が0になるまで声をかける
3. 見慣れない端末のアラートが出たら、本人に確認する（責めるためではなく、事実の確認）
4. 「使われていない」と出た端末を棚卸しする（既定は60日。設定で変えられます）

---

## 4. まだ決まっていないこと

説明の前に、会社として決めておいたほうがよいことです。

- **私物の端末から社内システムに入ることを、認めるか禁じるか**
- **深夜・休日のアラートを、本人にも知らせるか**（いまは管理者だけ）
- **「使われていない」を何日とするか**（既定60日）
- 就業規則にこの仕組みを書くか、書くならいつの改定で入れるか

3つめは画面の設定で変えられます。1・2・4は運用の決めごとです。
