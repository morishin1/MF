# 端末管理 メンバー向け案内（そのまま読める版）

メンバーに説明するときに使う原稿と手順です。

> **いま送る文章を探しているなら `docs/device-announce.md` を先に読んでください。**
> この文書は運用の手引き全体（ブラウザ側＋会社貸与PCのソフト）です。
> そのうち「2026-09-16 時点で実際に動いていて、いま送ってよいぶん」だけを
> 切り出したものが `device-announce.md` にあります。
> **3章（WEB利用）はまだ送らないでください。取れていません。**

**画面に出ている文言と、この案内の文言をそろえてあります**（`api/devices/me.js`）。
片方だけ直すと「聞いた話と画面が違う」が起きるので、どちらかを変えるときは両方直してください。

---

## 0. この案内の考え方

**端末管理は会社ルールです。** 社員に「監視してよいですか」と許可を求める形にはしません。
会社として端末管理を行うことを事前に周知し、本人が内容を確認した日時を記録します。
**同意の取得ではなく、周知の記録です。** 社員側で拒否して解除する仕組みは作りません。

説明で使う言葉をそろえてください。

| 使う | 使わない |
|---|---|
| 会社貸与PCの端末管理 | 監視 |
| 情報セキュリティ・業務管理・労務管理 | 許可 |
| 利用状況の記録 | 同意してください |
| この端末を登録する | 承認します |

もうひとつ、大事な線引きがあります。

> **何をしているかは隠さない。ただし、避ける方法につながる細かな検知条件や判定基準までは公開しない。**

だから社員向けには**大分類だけ**を伝えます。しきい値・アラートの条件・判定のしかたは出しません。
正確な仕様は管理者・開発者向けに別に書いてあります（`docs/device-management.md`、
`docs/device-web-history.md`）。**社員向けの説明と、内部の仕様書を混ぜないでください。**

話は2段階に分かれています。

| | いつ | 何を |
|---|---|---|
| **1〜2章** | いま | ブラウザ側だけ。社内システムにどの端末から入っているか |
| **3章** | 実機検証と規程整備のあと | 会社貸与PCに入れる端末管理ソフト |

## 1. 集まってもらって話すこと（2〜3分）

> 社内システムに**どの端末から入っているか**を台帳にします。
>
> 目的は、**会社のパソコン以外から社内の情報が見られていないか**を確かめることです。
> 退職した人の端末がまだ入れてしまう、といったことに気づけるようにするためのものです。
>
> **働きぶりを点数にしたり、評価に直接使ったりはしません。**

### 記録すること

- この端末から社内システム（このサイト）に入ったこと
- その端末の種類（Windows／Mac、ブラウザの名前、画面の大きさ）
- 社内システムを開いていた時間の、1日の合計
- そのうち深夜・休日にあたる時間

> この画面だけの場合、対象は**社内システムを開いているあいだ**です。

### 業務に使うパソコン

> 会社の業務、社内システムへのアクセス、会社データの閲覧・保存・編集は、
> **原則として会社貸与PCを使用してください。私物PCでの業務利用は禁止します。**
> やむを得ず私物PCを使う必要があるときは、**事前に管理者の承認**を受けてください。

承認は期限つきです。期限が来たら、また事情を説明してもらいます。

### みなさん側からも見えます

> 自分の端末情報は、いつでもマイページから見られます。
> **管理者があなたの端末情報を開いたときは、その記録もあなたの画面に残ります。**

---

## 2. やってもらうこと（1人1分）

1. この案内（`docs/device-announce.md` の文章）を読んでもらう
2. **https://mf.8grp.co.jp/pc** を押してもらう
3. 「**この端末を登録する**」を押す

**画面には、記録する内容の説明を置いていません（依頼により外しました）。**
だから **1 を省いてリンクだけ送ってはいけません。** 何も伝えないまま
登録させることになります。周知は、送る文章のほうで行います。

**3 を押してもらうまで、利用時間は1分も数えません。** 押した日時が残ります。
押していない端末は管理画面に「本人の確認待ち」として残り、管理者から声がかかります。

押したあと、同じ画面でできること（任意）:

- 端末に分かりやすい名前を付ける（例:「事務所のノート」）
- 自分が使っている端末の一覧を見る
- 管理者がいつ自分の端末情報を見たかを確かめる

> 端末を台帳から外すのは管理者です。返却のときにこちらで外します。

### よく出る質問

| 聞かれること | 答え |
|---|---|
| 断ることはできますか | 会社ルールとして行うものなので、解除はできません。内容についての質問は人事へどうぞ |
| 私物のスマホで見てもいいの | 業務は原則、会社貸与PCです。必要な事情があれば事前に相談してください |
| 家のパソコンから入ったら | 台帳に無いパソコンとして印が付きます。事情を確認させてください |
| 何を見ているか全部分かるの | この画面だけなら、社内システムを開いた事実と時間です |
| 押さないとどうなる | 「確認待ち」として残り、管理者から声がかかります |
| 自分で端末を外せますか | 外せません。返却のときに管理者が外します |

## 3. 会社貸与パソコンに入れる端末管理ソフト

ここから先は、**会社が貸しているパソコン**の話です。私物PCには入れません。

1〜2章（ブラウザ側）は、社内システムを開いているあいだだけが対象です。
3章のソフトを入れると、**そのパソコンを使っているあいだ**が対象になります。
受け取り方が変わるので、入れる前に必ずこの章を読んでもらってください。

### 3-1. 話すこと（3〜5分）

そのまま読める文です。画面に出ているものと同じです。

> 会社貸与PCでは、情報セキュリティ・業務管理・労務管理のため、
> 端末・アプリケーション・WEB・外部機器等の利用状況を記録します。
> 業務管理上必要のない個人情報を取得することを目的とはしていません。
> 詳細な取得方法・検知条件・セキュリティ判定基準については、
> 情報セキュリティ上の理由から公開していません。

※ 上は定型の言い回しです。**実際に何を記録しているかは、次の「記録する範囲」のとおり**です。

#### 記録する範囲

- グループウェアの利用状況（ログイン・最終アクセス・操作中／離席）
- WEBの利用状況（見たサイトの種類・ドメイン・見ていた時間）
- 勤怠・日報・タスクの記録
- セキュリティ上必要な端末情報（OS・ブラウザ・端末の識別子）

**この4つだけを伝えてください。**
「何分から」「どの条件で」「どう判定して」は説明しません。
聞かれたら「情報セキュリティ上の理由から公開していません」と答えてください。
はぐらかしているのではなく、**避ける方法を配らないため**だと説明すれば伝わります。

**取っていないものを「記録します」と言わないでください。**
USBメモリの接続、パソコンのアプリの利用、ソフトの追加・削除、
パソコンの起動・終了は、**いまの標準の形では取っていません**。
これらは、会社が別に「高度な端末管理ソフト」を入れたパソコンでだけ記録されます。
入れた人には、画面にその一覧が追加で出ます（入れていない人には出ません）。

多く取ることと同じくらい、**取っていないものを取ると言うこと**が信用を落とします。

#### 勤務時間の内と外

> 業務や働き方を見るために使うのは、**原則として勤務時間内**のぶんです。

高度な端末管理ソフトを入れたパソコンでは、
外部機器の接続やソフトウェアの変更など、安全管理に関わる記録は時間外も対象です。

#### 目的

> 情報セキュリティ、業務管理、労務管理のために行うものです。
> 働きぶりを点数にしたり、評価に直接使ったりするためのものではありません。

#### 自分でも見られます

> 自分の端末情報は、いつでもマイページから確認できます。
> **管理者があなたのWEB利用を開いたときは、その記録もあなたの画面に残ります。**

### 3-2. 入れる日の流れ

**本人が、自分のパソコンで、マイページから始めます。**
管理者が登録コードを発行して渡す運用はありません。

**始めるのは本人。入れるのは管理者・IT担当。**
役割をこう分けてあります。

| | 誰が |
|---|---|
| 会社貸与PCへのソフト導入 | 管理者・IT担当 |
| 端末管理ルールの確認 | 本人 |

```
本人が、その会社貸与PCで
  ① マイページ →「会社PCのセキュリティ設定」
  ②「この会社PCを設定する」を押す → ファイルが落ちてくる
  ③ この画面を開いたまま、管理者にかわる

管理者・IT担当が
  ④ 落ちてきたファイルを実行する
  ⑤ Windows の警告と管理者権限を処理する
  ⑥ Agent・Chrome・Edge の連携まで設定する

本人が
  ⑦ 画面が自動でもどってくる
  ⑧「このパソコンを登録する」を押す → 完了
```

**社員がするのは ①②⑧ だけ**、実質は「内容の確認」です。
登録コードの入力・社員名の選択・コマンド・拡張の手動設定は、どれもありません。

> **落としたファイルの名前は変えないでください。**
> 名前に、その人のための1回きりの合図が入っています。
> 変えてしまっても設定はできますが、途中で1回、確認の画面が増えます。

#### Windows の警告について、社員に何と言うか

商用のコード署名証明書を使わない方針なので、⑤ の警告は出ます。
**社員にこれを越えさせません。**

> 警告が出たら、そのまま管理者にお任せください。
> ご自身では進めないでください。
> メールやウェブで届いたファイルの警告も、無視してはいけません。

「警告が出たら詳細情報→実行」を社員に覚えさせると、
本物の怪しいEXEでも同じことをするようになります。
セキュリティ教育として割に合わないので、そこは管理者が引き受けます。

> 将来、警告なしで配れる道ができたら、設定（`self_install`）を切り替えるだけで
> 社員が自分で入れる形になります。そのときは画面の案内も自動で変わります。

⑧ は会社ルールの周知を受けた記録です。押した日時が残ります。
本人が押せない事情があるときは、管理者が対面・書面で周知し、
管理画面の「周知済みにする」で記録できます（そのとき、いつどう周知したかを残します）。

### 3-3. よく出る質問

| 聞かれること | 答え |
|---|---|
| 何を記録しているの | 上の6つの範囲です。細かい取得方法は、情報セキュリティ上の理由から公開していません |
| 隠しているということ？ | 記録していること自体はお伝えしています。公開していないのは検知条件と判定基準だけです |
| 私用のサイトを見たら怒られる？ | 自動で「違反」とは判定しません。管理者が確認するための材料です |
| 昼休みや退勤後は | 働き方を見るのは原則として勤務時間内です。安全管理に関わる記録は時間外も対象です |
| 私物のパソコンにも入れるの | 入れません。会社が貸しているパソコンだけです |
| 入れたあと自分で見られる？ | マイページで見られます。管理者が開いたことも残ります |
| 断れますか | 会社ルールとして行うものなので、解除はできません |
| 警告が出たけど大丈夫？ | ご自身では進めず、管理者にお任せください。メールやウェブで届いたファイルの警告も無視しないでください |
| 自分で入れてもいい？ | いまは管理者・IT担当が入れます。会社貸与PCへのソフト導入は管理者の役割です |
| 登録コードはどこでもらうの | 要りません。マイページから始めれば、誰のPCかは分かっています |

## 4. 管理者がやること

**システム管理 → 端末管理**（`admin-devices.html`）

| タブ | 見るもの |
|---|---|
| 端末 | 台帳の全部 |
| アラート | 確認が要るもの |
| 私物PCの承認 | やむを得ない私物PC利用の事前承認 |
| 設定 | アラートの条件・保存期間 |

> 「登録コード」タブは無くなりました。
> 端末の登録は本人がマイページから行うので、管理者がコードを配る作業はありません。

### 一覧の見方

一覧では、**細かい情報を出しません**。

```
田中太郎 / DESKTOP-A123 / Windows 11
  ● Agent 接続中   ● Chrome 連携済   ● Edge 連携済     最終通信 3分前
```

| 印 | 意味 | すること |
|---|---|---|
| ● 緑 | つながっている | 何もしなくてよい |
| ● 黄 | 入っているが、まだ本人の確認待ち | 声をかける |
| ● 赤 | 届いていない | ソフトが止まっているか、拡張が消されている |

1日ごとの様子は **○ 正常 / △ 要確認 / × 異常** だけ。
**全部緑で最終通信が新しければ、それ以上は開かなくてよい**、という見方です。
正常な社員を細かく見るための画面ではありません。

**詳細は、△ か × の端末を開いたときにだけ見ます。**
そこで PC利用・アプリ利用・WEB利用・外部機器・ソフトウェア変更・
Agent の状態・過去の要確認履歴が見られます。

**管理者が詳細を開いたことは、本人の画面に残ります。** 開く前にそれを承知しておいてください。

### 毎週まわすこと

管理画面TOPに「端末管理でやること」が出ます。**週に1回まわして、どちらも0にします。**

1. **本人の確認待ち** … 「まとめてお知らせを送る」で促す。押されないままなら声をかける
2. **未確認のアラート** … 内容を見て「本人に確認した」か「見たが問題なし」を押す

△ は「違反」ではなく「確かめてください」の印です。確かめずに閉じると、
この仕組みは数字を消すだけの作業になります。

### 未登録・私物のパソコン

台帳に無いパソコンから社内システムに入られると、アラートに出ます。
一覧では「未登録・私物の可能性」で絞り込めます。

1. 本人に事情を聞く（責めるためではなく、事実の確認）
2. 会社貸与なら区分を「会社貸与」にする
3. 私物で、やむを得ない事情があるなら「私物PCの承認」から期限つきで承認する
4. そうでなければ、会社貸与PCを使うよう伝える

**禁止だけを言うと、黙って使われます。** 通る道を残して、記録に載せるほうを選びます。

## 5. まだ決まっていないこと

説明の前に、会社として決めておいたほうがよいことです。

- **端末管理規程（または就業規則）に、いつの改定で入れるか**
- **未登録・私物のパソコンから入られたときの扱い**
  （いまは管理画面に出すだけ。警告・管理者通知・ログイン制限・アクセス拒否まで
  選べる作りにしてありますが、止める側はまだ実装していません）
- **「使われていない」を何日とするか**（既定60日）
- **△ が出たとき、誰がいつ本人に確かめるか**

保存期間は社内の管理基準で定めてあり、期間を過ぎたものは毎晩自動で消えます。
**具体的な日数は社員に伝えません**（期間が分かると、それに合わせた行動をとる余地が生まれます）。
実際の設定は `docs/device-spec-internal.md` と、画面の「設定」にあります。

> **3章（端末管理ソフト）は、端末管理規程に書いて周知するまで配らないでください。**
> WEBの利用状況を記録することは、書いていないまま始めてよい話ではありません。
