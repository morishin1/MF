# 端末管理 メンバー向け案内（そのまま読める版）

メンバーに説明するときに使う原稿と手順です。
**画面に出ている文言と、この案内の文言をそろえてあります**（`lib/devices.js` / `api/devices/me.js`）。
片方だけ直すと「聞いた話と画面が違う」が起きるので、どちらかを変えるときは両方直してください。

話は2段階に分かれています。

| | いつ | 何を |
|---|---|---|
| **1〜2章** | いま | ブラウザ側だけ。社内システムにどの端末から入っているか |
| **3章** | 実機検証のあと | パソコンに入れる会社のソフト（エージェント） |

3章はまだ配っていません（`docs/device-agent-testing.md` の検証が先）。
配るときも、入れるのは管理者か社内IT担当です（`docs/device-zero-cost.md`）。
**1〜2章だけ先に進めても、運用は回ります。**

---

## 1. 集まってもらって話すこと（2〜3分）

> これから、社内システムに**どの端末から入っているか**を台帳にします。
>
> 目的は、**会社のパソコン以外から社内の情報が見られていないか**を確かめることです。
> たとえば、退職した人の端末がまだ入れてしまう、私物のスマホから見られている、といったことに
> 気づけるようにするためのものです。
>
> **働きぶりを点数にしたり、評価に使ったりはしません。**
> 深夜や休日の利用を見ているのは、働きすぎに気づくためです。

### 記録すること

- この端末から社内システム（このサイト）に入ったこと
- その端末の種類（Windows／Mac、ブラウザの名前、画面の大きさ）
- 社内システムを開いていた時間の、1日の合計
- そのうち深夜・休日にあたる時間

### 記録しないこと

- キーボードで打った内容
- パスワード
- メールやチャットの本文
- 画面の録画・スクリーンショット
- 社内システム以外で見たページ
- パソコンに入っているソフト、USBメモリ、ファイル
- パソコンの電源が入っていた時間

> 分かるのは、**mf の画面を開いているあいだのこと**だけです。
> ブラウザを閉じているあいだ、パソコンが何をしていたかは分かりません。

### みなさん側からも見えます

> 自分の記録は、いつでもマイページから見られます。
> **管理者があなたの記録を開いたときは、それもあなたの画面に残ります。**
> 会社から一方的に見るのではなく、お互いに見える形にしてあります。

---

## 2. やってもらうこと（1人1分）

1. **mf にログインする**（いつもどおり）
2. **マイページ** を開く
3. 「**端末の設定・アプリとして入れる**」を押す
4. 出てきた内容を読む
5. 「**このパソコンです**」を押す

**5 を押してもらうことが肝心です。**
端末そのものはログインした時点で台帳に載りますが、
**本人が押すまで、利用時間は1分も数えません**。押さないと「本人の確認待ち」のまま溜まります。

押したあと、同じ画面でできること（任意）:

- 端末に分かりやすい名前を付ける（例:「事務所のノート」）
- 自分が使っている端末の一覧を見る
- 使わなくなった端末を自分で外す
- 管理者がいつ自分の記録を見たかを確かめる

### よく出る質問

| 聞かれること | 答え |
|---|---|
| 私物のスマホで見てもいいの | 会社の決まり次第です。台帳には載りますが、載ること自体が悪いわけではありません |
| 家のパソコンから入ったら怒られる？ | 見慣れない端末として印が付きます。理由が分かっていれば問題ありません |
| 何を見ているか全部分かるの | 分かりません。mf を開いた事実と時間だけです |
| 押さないとどうなる | 「確認待ち」のまま残り、利用時間は数えません。管理者から声がかかります |
| あとからやめられる | 端末を外せます。ただし社内システムを開けば、また載ります |

## 3. パソコンに会社のソフトを入れるとき（エージェント）

ここから先は、**会社が貸しているパソコン**の話です。
私物のパソコンには入れません。

1〜2章（ブラウザ側）は、mf の画面を開いているあいだしか分かりません。
3章のソフトを入れると、そのパソコンで何をしていたかが分かるようになります。
**段違いに踏み込むので、入れる前に必ずこの章を読んでもらってください。**

### 3-1. 話すこと（3〜5分）

> 会社が貸しているパソコンに、会社のソフトを入れます。
>
> 目的は2つです。
> **会社のパソコンから、お客様の情報が外に出ていないかを確かめること。**
> **在宅勤務のときの働き方を見ること。**
>
> 働きぶりを点数にしたり、評価に直接使ったりはしません。

#### 追加で記録すること

- パソコンの起動・終了・ログオン・ロック・スリープの時刻
- 1日の稼働時間と、離席していた時間
- 使ったソフトの名前と、その合計時間
- USBメモリをつないだこと、ソフトを入れたこと
- 見たサイトの **ドメインとページの場所**（例：`example.com/news/`）、
  その種類、見ていた時刻と時間

最後の1つが重い項目です。ぼかさずにそのまま伝えてください。
「履歴に残っていた」だけでなく、**そのタブを実際に見ていた時間**を数えます。

#### 記録しないこと

- キーボードで打った内容
- パスワード
- メールやチャットの本文
- 画面の録画・スクリーンショット
- 開いていた画面のタイトル
- ページの中身
- **検索したことば**（URLの `?` から後ろは送りません）
- フォームに入れた内容
- Cookie・ログインの鍵
- ファイルの中身

#### アドレスはどこまで削るか

> アドレスのうち、`?` から後ろ（検索したことば・メールアドレス・ログインの鍵が
> 入るところ）と `#` から後ろは、**このパソコンの中で捨ててから**送ります。
> 一度きりのリンクに見える部分も伏せます。

つまり、こう変わります。

| 実際に開いたもの | 会社に届くもの |
|---|---|
| `google.com/search?q=新宿 ランチ` | `google.com`（検索したことばは消える） |
| `example.com/news/2026/kessan` | `example.com/news/2026/kessan` |
| `bank.co.jp/login?token=xxxx` | `bank.co.jp/login` |

#### 勤務時間の内と外

> 働き方を見るために使うのは、**原則として勤務時間内のぶん**だけです。
> USBの抜き差しやソフトの出入りのような、情報漏えいに関わる記録は
> 時間外でも残ります。

#### 自分でも見られます

> 自分が見られている記録は、いつでもマイページから確認できます。
> **管理者があなたのWEB利用を開いたときは、それもあなたの画面に残ります。**

### 3-2. 入れる日の流れ

**入れるのは管理者か社内IT担当です。** 本人に操作は頼みません。

会社の証明書（コード署名証明書）を買わない方針なので、
インストールのときに Windows の警告が出ます。
社員に「警告を無視して実行してください」と覚えさせると、
本物の怪しいEXEでも同じことをするようになるので、
**警告を押すのは管理者だけ**にしてあります。

```
管理者が対象のパソコンで
  ① EIGHT-Agent-Setup.exe をダブルクリック
  ② 警告が出たら「詳細情報」→「実行」   ← 管理者が押す
  ③ 「変更を許可しますか」→ はい
  ④ ブラウザが自動で開く
  ⑤ 「このパソコンを使う人」で、その社員を選ぶ
  ⑥ 「このパソコンです」を押す

本人が
  ⑦ 「記録すること」を読んで、確認を押す   ← ここまで記録は始まりません
```

- 本人がやるのは **⑦ だけ**です
- 登録コードを打つ、コマンドを使う、ブラウザ拡張を自分で入れる —— どれもありません
- Chrome / Edge の拡張は、①〜⑥ のあいだに一緒に入ります

**⑦ を押すまで、1件も記録しません。** 押していないパソコンは
管理画面で「本人の確認待ち」のまま残ります。

### 3-3. よく出る質問

| 聞かれること | 答え |
|---|---|
| 何を検索したか分かるの | 分かりません。`?` から後ろはパソコンの中で捨ててから送ります |
| 見ていたページの中身は | 取りません。ドメインとページの場所だけです |
| 私用のサイトを見たら怒られる？ | 自動で「不正」とは判定しません。長く続いたときに管理者へ「確認して」と出るだけです |
| 昼休みや退勤後は | 働き方を見るのは原則として勤務時間内だけです。USB・ソフトの出入りは時間外でも残ります |
| 私物のパソコンにも入れるの | 入れません。会社が貸しているパソコンだけです |
| 入れたあと自分で見られる？ | マイページで見られます。管理者が開いたことも残ります |
| 警告が出たけど大丈夫？ | 入れるのは管理者です。自分で警告を押す場面はありません |
| あとから外せる？ | 管理者に申し出てください。自分では外せません（会社の貸与品のため） |

## 4. 管理者がやること

**システム管理 → 端末管理**（`admin-devices.html`）

| タブ | 見るもの |
|---|---|
| すべて | 台帳の全部 |
| 未通信 | しばらく届いていない端末 |
| 本人の確認待ち | 2 の 5 を押していない人。**ここを毎週ゼロにするのが運用です** |
| ソフト導入済み | エージェントを入れたパソコン（いまは0台） |
| 登録コード | 発行・使用の記録（エージェント用。いまは使いません） |

エージェントを入れたパソコンは、**1台1行**で出ます。

```
田中太郎 / DESKTOP-A123 / Windows 11
  ● Agent 接続中   ● Chrome 連携済   ● Edge 連携済     最終通信 3分前
```

全部緑で最終通信が新しければ、それ以上は開かなくてよい、という見方です。
赤や黄が出ているパソコンだけ、行を押して中を見てください。

| 印 | 意味 | すること |
|---|---|---|
| ● 緑 | つながっている | 何もしなくてよい |
| ● 黄 | 入っているが、まだ本人の確認待ち | 本人に押してもらう |
| ● 赤 | 届いていない | ソフトが止まっているか、拡張が消されている |

1日ごとの様子は **○ 正常 / △ 要確認 / × 異常** だけ出ます。
細かいWEB履歴は、その社員を開いたときにだけ見られます。
△ は「不正」ではなく「確かめてください」の印です。

行を押すと、その端末の記録・アラート・所有者変更・紐付け解除ができます。
**管理者が記録を開いたことは、本人の画面に残ります。** 見る前にそれを承知しておいてください。

### 最初の1〜2週間

1. 全員に 2 をやってもらう
2. 「本人の確認待ち」が0になるまで声をかける
3. 見慣れない端末のアラートが出たら、本人に確認する（責めるためではなく、事実の確認）
4. 「使われていない」と出た端末を棚卸しする（既定は60日。設定で変えられます）

### エージェントを配ったあと

1. 1台入れたら、まず `docs/device-agent-testing.md` の §3 と §6-1 を通す
2. 通ってから、残りの貸与パソコンへ広げる
3. 毎週、赤と黄をゼロにする
4. △ が出たら、**その週のうちに**本人へ確かめる（溜めると言いにくくなる）

---

## 5. まだ決まっていないこと

説明の前に、会社として決めておいたほうがよいことです。

- **私物の端末から社内システムに入ることを、認めるか禁じるか**
- **深夜・休日のアラートを、本人にも知らせるか**（いまは管理者だけ）
- **「使われていない」を何日とするか**（既定60日）
- **WEB履歴を何日ぶん残すか**（既定90日）
- **△ が出たとき、誰がいつ本人に確かめるか**
- 就業規則（または端末管理規程）にこの仕組みを書くか、書くならいつの改定で入れるか

> **3章（エージェント）は、就業規則か端末管理規程に書いて周知するまで配らないでください。**
> WEBの利用状況を記録することは、書いていないまま始めてよい話ではありません。

「使われていない」日数と保存日数は画面の設定で変えられます。
残りは運用の決めごとです。
