- 企業名横の輪郭の炎を1回押すと🔥、再度押すと解除。PC一覧・スマホカード・詳細に共通表示。
- 手動の目印。進捗、確度、並び順、タスク、通知には影響しない。
- 現在担当本人またはSales管理者が編集。同テナントのSales利用者は閲覧のみ。アーカイブは変更不可。
- `db/150_sales_proposal_hot_marks.sql` を対象MF DBに適用。SQL149の同期機能とは独立。
- SQL未適用は無効な輪郭ボタン「設定待ち」。読取失敗は「読取確認待ち」。未取得をOFFとみなさない。
- 変更はRLS + caller JWT RPC。直接書込権限なし。proposal行ロック + version一致で競合拒否。変更履歴は同トランザクション。
- 画面は保存前にONにせず、保存後/通信結果不明ともに読戻し。連打は無効。結果不明で再送しない。
- CI: API/VM、Postgres互換PGliteで権限/他tenant/直接更新拒否/古いversion/同値冪等/監査/再適用、既存一覧ブラウザテスト。
