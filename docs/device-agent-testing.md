# Windows実機テスト チェックリスト

管理者PC1台で確かめる手順。**上から順に。** 途中で止まったら、そこで直す。

展開の順番は次のとおり。このチェックリストは **① の中身**。

```
① 管理者PC1台で検証   ← ここ
② 社内規程・告知の整備
③ 社員1名で2週間試験
④ 全員展開
```

> **社員が触るのは `EIGHT-Agent-Setup.exe` の1本だけ。**
> コマンドは使わせない。登録コードも打たせない。ブラウザ側の作業もさせない。
> この検証でも、**まずは社員と同じやり方で通す**。
> `-status` などのコマンドは、うまくいかなかったときに原因を見るために使う。

## 6. WEB利用が正しく取れること

**④ 全員展開の必須条件。ここが通らないうちは全員に配らない。**

Chrome と Edge で、次を順に開いて数分ずつ置く。

1. `mf.8grp.co.jp`（社内システム）
2. `chatgpt.com`（AI）
3. `google.com` で何か検索（検索）
4. `youtube.com`（動画）
5. `x.com`（SNS）

管理画面 → 端末管理 → そのPC → **［WEB利用］**

| | 確かめること |
|---|---|
| ☐ | カテゴリが **社内システム / AI / 検索 / 動画 / SNS** に分かれて出る |
| ☐ | 時間が、実際に見ていた長さとだいたい合う |
| ☐ | 履歴に **時刻・ドメイン・種類・時間・ブラウザ** が並ぶ |
| ☐ | Chrome で見たものは `chrome`、Edge で見たものは `edge` と出る |
| ☐ | 裏に置いたままのタブが、**数えられていない**（別のタブを見ているあいだは増えない） |
| ☐ | 1日の様子に **勤務 / PC稼働 / WEB利用 / アプリ利用 / 離席** が出る |

### 6-1. 取ってはいけないものが混ざっていないこと

**ここがいちばん大事。** わざと危ないものを開いてから確かめる。

やること：

- アドレスバーに `新宿 ランチ おすすめ` と**入力した状態**で1分置く（Enterは押さない）
- `google.com` で `転職 エージェント 30代` を検索する
- `https://example.com/orders/12345?customer=yamada&token=abcdef123456` を開く
- Gmail を開いてメールを1通読む

Supabase で：

```sql
-- 1) 検索語・個人名・鍵が混ざっていないか
select distinct host, path from public.gw_device_web_visits
 order by host;

-- 2) ? や # や空白が残っていないか（0件であること）
--    本物のURLのパスに生の空白は入らない（%20 になる）。
--    空白が残るのは、打ちかけの検索語を読んでしまったときだけ
select count(*) from public.gw_device_web_visits
 where path like '%?%' or path like '%#%' or path like '% %';

-- 3) カテゴリが決めた9語だけか
select distinct category from public.gw_device_web_visits;
```

| | 確かめること |
|---|---|
| ☐ | **1) に「新宿」「転職」「ランチ」などの語が1つも無い** |
| ☐ | **1) に `yamada` も `abcdef123456` も無い**（`example.com` と `/orders/…` だけ） |
| ☐ | **2) が 0 件** |
| ☐ | 3) が `internal / work / search / ai / research / sns / video / shopping / other` だけ |
| ☐ | Gmail は `mail.google.com` と `/mail/u/0` までで、**メールのIDが無い** |
| ☐ | 管理画面の履歴にも、上と同じものしか出ていない |

→ ここに検索語や個人名が1つでも出たら、**全員展開を止める。**

### 6-2. 勤務時間の内と外

| | 確かめること |
|---|---|
| ☐ | タイムカードで出勤打刻 → その後に見たサイトが「勤務時間内」に入る |
| ☐ | 退勤打刻 → その後に見たサイトは、既定の表示に**出てこない** |
| ☐ | ［時間外も含む］に切り替えると出る |
| ☐ | 切り替えたとき「働き方を見るときは『勤務時間内』で見てください」と出る |
| ☐ | 打刻をしていない日は、会社の既定（9:00〜18:00）で分かれる |

### 6-3. 一覧には細かい履歴を出さないこと

| | 確かめること |
|---|---|
| ☐ | 台帳の一覧に、**ドメインもURLも1つも出ていない** |
| ☐ | 出ているのは ○ / △ / × と、状態だけ |
| ☐ | 勤務中にSNS・動画を90分以上見ると **△ 要確認** になる |
| ☐ | その日の記録が届いていないと **× 異常** になる |
| ☐ | ［WEB利用］の中に「これは『不正』の判定ではありません」と出ている |

## 12. 片付け

検証が終わったら：

| | 確かめること |
|---|---|
| ☐ | 管理画面でこのPCを **使用終了** にする |
| ☐ | `sc stop EightAgent && sc delete EightAgent` |
| ☐ | `C:\Program Files\EIGHT\` と `C:\ProgramData\EIGHT\` を消す |

```sql
-- 検証に使った端末の記録を消す。device_id は管理画面の詳細に出ている
delete from public.gw_device_web_visits where device_id = '（そのPCのID）';
delete from public.gw_device_usage      where device_id = '（そのPCのID）';
```
