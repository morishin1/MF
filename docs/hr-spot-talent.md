# HR スポット人材（タイミー） Phase 1

## 変更する場所
- `/hr/applicants.html` の既存区分タブに **スポット人材** を追加。
- 遷移先は `/hr/spot.html`。通常応募者の表・ステータスを変更せず、同じHRヘッダーを使う。
- 本人アンケートは `/hr/spot-survey.html#token=...`。ログイン不要、回答任意。

## スタッフの操作
1. 採用HRの応募者 → スポット人材 → ［スポット人材を登録］：タイミー表示名、勤務日。
2. 対象者を開き、［アンケートURLを発行］。発行直後に表示されたURLをコピー、またはQRコードを本人へ提示する。発行し直すと前のURLは無効。14日で期限切れ。
3. 本人は任意アンケート（業務感想、継続意思、曜日/時間、興味分野など）を1回だけ送信。連絡同意がある場合だけ連絡先メールを入力。
4. 工藤さん・中村さんなどの担当者が5項目各1〜5点で社内評価。
5. 本人が「ぜひ継続したい／条件が合えば」を選び、連絡同意もある場合［長期採用候補］へ。
6. ［HRの選考中へ引き継ぐ］で、重複メールのない人を `gw_hr_applicants` に作成（stage=applied / status=todo）。以降は既存HRの面談・通知・同意フローを使い、OFFICEへの手渡しには触らない。

## DB
- `db/145_hr_spot_talents.sql` を **本番適用前に承認**。既存テーブルを変更しない。
- `db/check_145_hr_spot_talents.sql` で表・RLS確認（個人情報を取得しない）。
- `db/rollback_145_hr_spot_talents.sql` は登録済みデータが存在すると削除を拒否。
- RLSは採用担当の参照のみ許可。APIからの操作は採用権限＋テナント境界を確認してservice_roleで行う。
- 本人URLは256bit乱数、DBにはSHA-256ハッシュのみ、URL fragmentで渡す。外部のQR生成サービスには送らない。
