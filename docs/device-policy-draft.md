# 端末管理規程（ひな形）

社内で整えるための下書きです。**このまま施行できるものではありません。**
条番号・施行日・窓口・社名は埋めてください。**社会保険労務士の確認を受けてから**施行してください。

> なぜ要るのか
>
> 端末の利用状況を記録することは、書いていないまま始めてよい話ではありません。
> 会社ルールとして行う以上、ルールが書いてあり、周知されていることが前提になります。
> **この規程を整えて周知するまで、エージェント（3章）は配らないでください。**

---

## 第1条（目的）

この規程は、当社が貸与するパソコン等の情報機器（以下「会社貸与PC」という）の
利用および管理について必要な事項を定め、情報セキュリティの確保、業務の適正な管理
および労務管理の適正化を図ることを目的とする。

## 第2条（適用範囲）

1. この規程は、当社の従業員（雇用形態を問わない）に適用する。
2. 業務委託先等に会社貸与PCを貸与する場合は、契約においてこの規程に準じた取扱いを定める。

## 第3条（会社貸与PCの使用）

1. 業務、社内システムへのアクセス、および会社データの閲覧・保存・編集は、
   原則として会社貸与PCで行わなければならない。
2. **私物のパソコンを業務に使用してはならない。**
3. 前項にかかわらず、やむを得ない事情があるときは、あらかじめ会社の承認を受けた場合に限り、
   期間を定めて私物のパソコンを使用することができる。
4. 前項の承認にあたり、会社は対象者、対象端末、理由、承認者および利用期限を記録する。
5. 会社貸与PCを、業務に必要な範囲を超えて私的に使用してはならない。

## 第4条（端末管理）

1. 会社は、第1条の目的のため、会社貸与PCの利用状況を記録し、管理する。
2. 記録する範囲は次のとおりとする。
   1. 端末の利用状況
   2. アプリケーションの利用状況
   3. WEBの利用状況
   4. 外部機器の接続状況
   5. ソフトウェアの変更状況
   6. セキュリティ上必要な端末情報
3. 会社は、業務管理上必要のない個人情報を取得することを目的としない。
4. 会社は、次の情報を取得しない。
   1. キーボードにより入力された内容およびパスワード
   2. 電子メールおよびチャットの本文
   3. 画面の録画および画面の画像
   4. 閲覧したページの内容およびフォームに入力した内容
   5. Cookie および認証情報
   6. ファイルの内容
5. 詳細な取得方法、検知条件およびセキュリティ判定基準は、
   情報セキュリティ上の理由から公開しない。

## 第5条（周知および確認）

1. 会社は、この規程および端末管理を行うことを、あらかじめ従業員に周知する。
2. 従業員は、周知された内容を確認し、社内システムにおいて確認の記録を行うものとする。
3. **前項の確認は、端末管理の実施に対する同意を求めるものではなく、周知の記録とする。**
4. 会社貸与PCについて、従業員が端末管理の解除を求めることはできない。
5. やむを得ない事情により第2項の確認ができない場合、会社は書面または口頭により周知し、
   その経緯を記録する。

## 第6条（記録の利用目的）

1. 会社は、記録した情報を次の目的に限り利用する。
   1. 情報セキュリティの確保および情報漏えいの防止
   2. 業務の適正な管理
   3. 労務管理（長時間労働の把握を含む）
   4. 貸与機器の管理および棚卸
2. 会社は、記録した情報を、**人事評価の直接の根拠として用いない**。
3. 記録により確認が必要な事象が認められた場合、会社は本人に事実を確認する。
   **記録のみをもって懲戒その他の不利益な取扱いを行わない。**

## 第7条（対象とする時間）

1. 業務および勤務状況の確認のために用いる記録は、原則として所定労働時間内のものとする。
2. 前項にかかわらず、外部機器の接続、ソフトウェアの変更その他の情報セキュリティに関する事象は、
   所定労働時間外においても記録する。

## 第8条（保存期間）

1. 会社は、記録した情報の保存期間を定め、期間を経過したものは消去する。
2. 保存期間は、利用目的に照らして必要な範囲とし、会社が別に定める。
3. 会社貸与PCの使用を終了したときは、その端末に係る記録を所定の期間の経過後に消去する。

> 具体的な日数は、社内の管理基準（`docs/device-spec-internal.md`）に定めます。
> 規程には書きません。期間を公開すると、それに合わせた行動をとる余地が生まれます。

## 第9条（閲覧および閲覧の記録）

1. 記録を閲覧できる者は、人事担当者および会社が指定した管理者に限る。
2. 従業員は、自己に係る記録を社内システムにおいて確認することができる。
3. **管理者が従業員の詳細な記録を閲覧したときは、その事実を記録し、本人が確認できるものとする。**

## 第10条（未登録の端末）

1. 会社が把握していない端末から社内システムへのアクセスがあったときは、会社はその事実を記録し、
   本人に事情を確認する。
2. 会社は、情報セキュリティ上必要があると認めるときは、当該端末からのアクセスを制限し、
   または拒否することができる。

## 第11条（遵守事項）

従業員は、会社貸与PCの利用にあたり、次の事項を守らなければならない。

1. 会社の許可なくソフトウェアを導入しないこと
2. 会社の許可なく外部記憶媒体を接続し、会社データを複製しないこと
3. 端末管理の仕組みを停止し、または回避しないこと
4. 会社貸与PCを第三者に使用させないこと
5. 紛失・盗難・故障が生じたときは、直ちに会社に報告すること

## 決めていただきたいこと

| | 選択肢 |
|---|---|
| 未登録端末からのアクセス | 記録するだけ／本人に警告／管理者に通知／制限／拒否 |

| 深夜・休日のアラートを本人にも知らせるか | いまは管理者だけ |
