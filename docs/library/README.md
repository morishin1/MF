# 社内情報（ライブラリ）に載せる規程

配布は mf.8grp.co.jp の「社内情報」→「社内文書・様式」（library.html）から。
登録は管理画面の「社内文書・雛形」（admin-docs.html）で、
ファイルを上げるか Google ドライブのリンクを貼るかのどちらか。

ここに置いてあるのは版を追うための控えで、配布の実体はライブラリ側にある。

| 文書 | 版 | 実装との関係 |
|---|---|---|
| 人事評価基準 | 2.0 | `lib/scoring.js` の配点と一致（成果40/行動30/成長20/チーム10）。自走レベルは `lib/autonomy.js` |
| 社内ルール（メンバー向け） | 1.1 | 勤怠はタイムカード。電子確認の記録項目は `db/039` と一致 |
| 昇給・賞与・給与ルール | 1.0 | 実装と矛盾なし。人事評価基準を参照している |

## 直すときの順番

配点や条件を変えるときは、**実装（`lib/scoring.js` / `lib/autonomy.js`）を正**として、
この文書を合わせる。画面に出る点数と規程が食い違うと、本人がどちらを信じてよいか分からなくなる。

入社時に同意してもらう3点（誓約書・個人情報の取扱い・社内ルール確認書）は
`docs/consent/` にあり、そちらは `lib/consent-docs.js` が本文の正。
