# ENGER 30分商談・企業専用ページ 操作マニュアル（社内用）

**対象**：Sales営業担当、ENGER担当、管理者  
**目的**：誰が担当しても30分で商談を進め、提案の継続・面談・案件／人材の収集につなげる。  
**公開情報**：この文書は社内限定。企業には営業トーク、AI評価、パートナー名、仕入価格を見せない。

## 1. 商談を始める
1. グループウェアの **Sales → ダッシュボード → 商談を始める**。
2. 「既存企業から選ぶ」か「新規企業を登録」を選択。
3. 新規は**企業名または13桁の法人番号**で公的API検索し、法人名・所在地を確認して登録。重複企業は既存情報を使う。
4. 企業基本情報 → AI分析 → マッチング・提案の順に準備。AIの仮説は先方の確認前は確定情報にしない。
5. 企業担当者名・メールが不明でも**Sales側の商談は開始可能**。企業専用ログインの発行は最後まで延期する。
6. 人材・案件の公開可能性をチェックし、商談画面を開く。

## 2. 30分商談の標準時間とゴール
| ステップ | 時間 | 確認すべきこと |
|---|---:|---|
| 1. 会社概要 | 4分 | エイト・ENGERの事業と今日の流れを説明 |
| 2. 目的確認 | 2分 | 今回、何が決まれば成功か・意思決定者 |
| 3. 課題確認 | 7分 | 必要スキル・案件・予算・開始時期 |
| 4. 候補提案 | 10分 | 匿名候補を紹介しスキル・条件を確認 |
| 5. オファー | 4分 | 面談希望候補・追加条件・再提案条件 |
| 6. クロージング | 3分 | 提案確定・宛先確認・メール送信・次回対応 |

画面上部の進捗バーを確認し、中央の**営業トーク・質問・確認チェック**を読む。画面内のメモは社内専用。必要事項をチェックして保存後、次へ進む。確認できない項目は理由を記録してから進む。30分タイマーは目安であり、進行を強制終了しない。

## 3. クロージングの必須操作
1. **提案候補**：企業に紹介して面談希望・提案する人材・案件をチェックする。公開承認済みの候補のみ。
2. **宛先メール**：最後の3分に企業担当者から受領し、誤送信がないよう声に出して確認。担当者名は任意。
3. **結果区分**：「オファーあり」「再提案」「継続検討」「見送り」から選ぶ。
4. **次回アクション**：誰がいつ何をするか、具体的に入力する。期限は分かれば設定。
5. **企業専用ページを発行して案内メールを送信**を押し、確認ダイアログで宛先・結果を確定。
6. 画面に **送信完了** が出てから商談終了。Salesの企業履歴・次回対応に引き継ぐ。**送信失敗は完了ではない**。

初回発行時は企業ログインIDと仮パスワードを自動生成。平文はDBに保存しない。既存アカウントは勝手にパスワード変更しない。送信トラブルの場合は新規発行を繰り返さず管理者へ連絡する。

## 4. 企業へ案内する内容
法人ログインURLのデザインはENGER for Businessのアイボリー・ネイビー・オレンジで統一。企業は新規登録せず、案内された企業IDまたはメールとパスワードでログインする。

ログイン後の企業専用ページ：
- **ご提案一覧**：公開済み人材・案件を見る／選ぶ／オファーする。オファーは契約確定ではない。
- **自社案件**：業務概要・必要スキル・単価・開始時期を下書き登録。
- **所属人材**：匿名概要・希望条件を登録、PDF/Excelスキルシートを非公開アップロード。
- **オファー履歴**：依頼済み候補と対応状況を確認。

登録した案件や人材は確認待ちで保存され、ENGER側の承認前に他社へ公開されない。

## 5. 業務上の判断基準
- 第一目標：**面談・オファー希望を取得**する。
- 第二目標：希望候補がなくても**具体的な案件・人材ニーズ、次回提案期限**を決める。
- 第三目標：見送り時は**理由（スキル・予算・時期・ニーズなし等）**を記録する。
- 会社説明に時間を使いすぎない。**課題確認＋候補提案が17分**、商談時間の過半を占める。
- 企業から新しい案件・所属人材が登録されたら、Sales/ENGERで確認・仕分けし、次の提案につなげる。

## 6. トラブル時
- **法人番号の検索結果がない**：表記や法人番号を確認、手入力・曖昧な名寄せで別法人と統合しない。
- **AI分析が押せない**：法人番号・企業ID・公式HP・権限を確認。AI仮説は未確認情報。
- **候補が0件**：会社・目的・課題確認から商談は開始できる。条件を記録して再提案へ。
- **担当者名・メールが不明**：商談開始は可能。メール送信時に宛先を確認する。
- **送信失敗**：送信済み扱いにせず、管理者に送信履歴とメール設定の確認を依頼。
- **企業ログインがフリーランス画面へ飛ぶ**：法人ログインURLでアクセスし、管理者にアカウントの所属アプリ設定を確認してもらう。
- **スキルシート**：PDF/XLS/XLSXで5MB以内。個人情報を含むため取扱権限・本人同意を確認。

**メンバーが作業完了を報告する条件**：画面に商談結果、メール送信履歴、次回アクションが保存されていること。送信完了と契約成立は別です。
