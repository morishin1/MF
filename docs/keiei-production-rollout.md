## 0. 進め方の約束

- 順番を入れ替えない。1ステップ終わるごとに、**合格条件を確かめて記録**（結果の画面写真か、値）し、満たさなければ**そこで止まる**（次へ進まない・「あとで直す」で進めない）。
- 止まったら、そのステップの「元に戻す」だけを行う（ほかのステップに手を付けない）。原因が分かるまで、再開しない。
- 実行は、**利用の少ない時間帯**に、**2人で**（実行者＋確認者）。SQL は、Supabase の SQL Editor に**1ファイルずつ**貼る。
- 本番の前に、**本番以外の環境**（Supabase の別プロジェクトか、ブランチ）で、同じ順で1回通す（できるなら）。
- 実行の前に、Supabase のバックアップ（Database → Backups）が、直近のものであることを確かめる。
- **アプリのコードは、SQL より先にデプロイしてよい**（この変更は、表が無くても止まらない作りで、環境変数を入れるまで動きを変えない）。
  ただし、`main` へのマージは、承認のあと。
