# Sales 提案管理：管理者全件操作・役割別担当プルダウン（2026-10-22）

## 仕様
- **管理者/経営者/マネージャー**：同じ会社の全提案のチェックボックスが操作でき、50件までの一括編集・削除（アーカイブ）・復元が可能。個別の記録・正式引継ぎも可能。
- **一般メンバー**：本人の提案への記録・一括操作は従来どおり。**担当欄のみ**、同じ会社のSalesメンバーを一覧で直接選べる（他人の提案でも可能）。
- 3列は **提案担当・CS担当・クロージング担当**。選択時点で保存。PCテーブル/スマートフォンのカードに対応。
- 役割の変更は「人員配置」。正式な工程変更とは別。提案→CS→クロージングの正式引継ぎ・CS判断の証跡とガードは維持。
- 人員配置が現在の工程に該当するなら、現在の営業担当と未完了の本人割当タスクも付替。過去の記録は書き換えない。
- 「削除」は復元可能なアーカイブ。提案、活動、監査履歴は消さず、未完了の対応タスクを取り消す。
- 同時更新は旧担当IDを比較し、先に更新された場合409を返す。別テナント・非在籍・Sales権限なしのメンバーへは変更不可。
- ENGERの提案元の担当文字名は別途保持し、一覧では「元：…」と表示。元システムへ変更を逆送しない。

## 本番確認
1. 管理者：担当が異なる3社をチェックし、アーカイブ。通常一覧から消え、アーカイブから復元できる。
2. 一般メンバー：他人の提案は電話/結果更新できないが、3担当のプルダウンは選べる。
3. 担当変更で履歴・監査ログが作られ、現在工程の本人タスクが新担当に移る。
4. 後続の正式引継ぎ操作は自動で起動しない。
5. 退職者・異なるテナント・競合変更・既にアーカイブ済みは適切なエラーが出る。
