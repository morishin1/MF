# MFクラウド会計「仕訳帳」インポートの確認（初回に1度）

画面が出す CSV（27列）が、実際の MFクラウド会計で取り込めるかを、**ダミーのデータ**で先に確かめる手順。

## 使うファイル

- `mf-journal_import-test.csv`（この README と同じ場所）
- または 画面の［MFクラウドCSV］→「インポート確認用のサンプルCSV」（同じ中身）

ダミーの4取引（摘要に【MFインポート確認用】が付く）：

| 取引No | 内容 | 確かめること |
|---|---|---|
| 1 | 仕入計上（単一）外注費 110,000／未払金 110,000・課対仕入10%・適格・取引先 テスト株式会社ABC | 基本の形・MF仕訳タイプ「債務」 |
| 2 | 仕入計上（複合）通信費 20,000＋消耗品費 30,000＋外注費 50,000（**70%控除**）／未払金 100,000 | 複合仕訳（同一取引No・同一取引日）・インボイス区分 70%控除 |
| 3 | 支払 未払金 110,000／普通預金 110,000・2026/11/30 | MF仕訳タイプ「経費・債務支払」 |
| 4 | 支払（複合）未払金 100,000＋支払手数料 330／普通預金 100,330 | 振込手数料つきの支払 |

## 手順

1. MFクラウド会計にログインし、［会計帳簿］→［仕訳帳］→［インポート］を開く（**テスト用の事業者・テスト期間で行う**ことをすすめる。本番の帳簿に入れる場合は、確認後に必ず削除する）。
2. `mf-journal_import-test.csv` を選ぶ。文字コードは **UTF-8**（BOM付き）。
3. 取り込めたら、次を見る。
   - 4取引が登録され、取引No 2 が **1つの複合仕訳**（借方3行・貸方1行）になっているか
   - 取引日（2026/10/31・2026/11/30）、金額、摘要、MF仕訳タイプ（債務／経費・債務支払）
   - 取引先・税区分・インボイス（適格／70%控除）が入っているか
   - タグ「MFインポート確認用」が付いているか
4. 確認が終わったら、**【MFインポート確認用】の仕訳を MF 側で削除する**。

## うまくいかなかったとき

| 症状 | 見るところ |
|---|---|
| 勘定科目・補助科目・部門・取引先・税区分でエラー | 名称が MF のマスタと**1文字でも**違う。画面の［設定］で候補を MF の正式名称に直す／支払先マスタの標準仕訳を直す（このサンプルの `課対仕入10%`・`対象外`・`外注費` などが MF で別の名称なら、`lib/office-invoice-defs.js` の既定の候補と `lib/mf-journal-csv.js` の `"対象外"` を直す） |
| 複合仕訳が1行ずつバラバラに登録される | 「余った側を空にする」書き方が合っていない。`lib/mf-journal-csv.js` の `entryRows` を直す（MF のエクスポート形式を、実際の複合仕訳で見て合わせる） |
| タグが1つの文字列になる | 複数タグの区切りが違う。`lib/office-invoice-defs.js` の `TAG_SEPARATOR`（既定 `\|`）を直す |
| 文字化け | 取込画面で文字コードを UTF-8 にする |
| 列数・見出しのエラー | 取込画面の見出しと `lib/mf-journal-csv.js` の `MF_COLUMNS` を見比べる |

直したら `node scripts/gen-mf-import-test.mjs` でこのサンプルを作り直し、`node test/mfjournalcsv.mjs` を通す。
