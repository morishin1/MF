# 同梱フォント

## ipagp.ttf — IPA Pゴシック

出所: Information-technology Promotion Agency, Japan（IPA）
      https://moji.or.jp/ipafont/

契約書のPDFを作るのに使っている（lib/pdf-jp.js）。
サーバ側で日本語のPDFを作るには、フォントの実体が要る。
標準14フォントは日本語を持っていないので、同梱するしかない。

IPAフォントライセンス v1.0（IPA_Font_License_v1.0.txt）で配布されている。
そのままの形で再頒布することが許諾されているので、ファイル名も変えていない。
作ったPDFにフォントを埋め込むことも、同ライセンスで明示的に認められている
（第3条 3項・4項）。

改変は行っていない。改変すると「派生プログラム」となり、
名称の変更など別の条件が付く。
