引数の YYYY-MM 月の経営レポートを生成してください。

## 入力
- `data/periods/YYYY-MM/trial_balance.json`
- 過去3〜12ヶ月の試算表（推移分析用）
- `data/periods/YYYY-MM/closing_checks.json`
- `data/company.json`

## 出力: `data/periods/YYYY-MM/report.md`

以下の構成で生成:

```markdown
# YYYY年M月度 経営レポート — {自社名}

## 1. サマリー
- 売上高: ¥X,XXX,XXX（前月比 +X.X% / 前年同月比 +X.X%）
- 売上総利益率: XX.X%
- 営業利益: ¥X,XXX,XXX
- 経常利益: ¥X,XXX,XXX
- 現預金残高: ¥X,XXX,XXX

## 2. 注目すべき変化
（前月比±20%以上の科目をピックアップして自然文で解説）

## 3. 推移グラフ
（report-generator.html で表示するためのデータ参照ノート）

## 4. 月次締めチェックの要点
（closing_checks.json から critical/warning だけ抜粋）

## 5. 来月への観察ポイント
（パターンから今後注意すべきトレンドを提示）

## 6. メモ欄
（自社で気づいた点を後から追記する空欄）
```

## 手順

1. 試算表データを読み込み、上記サマリーを計算
2. 過去推移と比較して特筆事項を自然文で記述
3. `closing_checks.json` から重要なものだけ要約
4. Markdown を `data/periods/YYYY-MM/report.md` に保存
5. バックアップ: `data/periods/YYYY-MM/` 全体を `backup/YYYY-MM.zip` に圧縮（PowerShellで `Compress-Archive`）
6. 監査ログ追記
7. 次のアクション: `report-generator.html` で確認 → 必要なら `/税理士共有 YYYY-MM`
