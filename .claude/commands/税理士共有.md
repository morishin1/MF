引数の YYYY-MM 月の税理士共有パッケージを生成してください。

## 目的
税理士は決算と月次相談のみに絞っているため、毎月の細かい仕訳承認は依頼しません。
代わりに、月次相談時に **必要十分な情報** を1つのパッケージで渡せるようにします。

## 出力
`data/periods/YYYY-MM/tax_share/` 配下に以下を生成:

1. `summary.md` — 月次レポートの要約版（数字＋気になる点）
2. `trial_balance.csv` — 試算表（科目別）をCSV化、Excelで開ける形式
3. `journals_highlight.csv` — 確認してほしい仕訳だけ抽出（confidence:low、金額50万円超、初出パートナー、closing_checksにヒットしたもの）
4. `closing_checks.md` — 月次締めで開いたままの項目
5. `questions.md` — こちらから税理士に確認したい質問リスト（空テンプレート、こちらで埋める）

## 手順

1. 上記5ファイルを生成
2. `tax_share/` 全体を `backup/tax_share_YYYY-MM.zip` にも圧縮
3. 送付方法の案内表示:
   - `data/company.json` の `tax_accountant.share_method` を確認（email / drive / notion）
   - 共有先のファイルパスをユーザーに提示
4. 監査ログ追記
