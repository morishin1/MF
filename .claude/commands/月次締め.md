引数の YYYY-MM 月の月次締めチェックを実行してください。

## 入力
- `data/periods/YYYY-MM/trial_balance.json`（事前に `/試算表取得 YYYY-MM` を実行済み）
- `data/periods/YYYY-MM/journals_sent.json`
- 過去3〜6ヶ月の試算表（推移比較用）

## 検出すべき項目

1. **預金残高差異**: 帳簿の預金残高と銀行明細の月末残高がズレている
2. **長期滞留**: 仮払金/仮受金/前払費用/未収入金が3ヶ月以上動いていない
3. **異常値**: 勘定科目別の月次残高が前月比±50%超変動
4. **計上漏れ疑い**: 月初〜月末の取引パターンから期待される定常費（家賃・通信費・給与など）が計上されていない
5. **税区分の不整合**: 売上高に「課対仕入」など明らかな誤りがないか
6. **負残高**: 通常借方科目（売掛金・現金など）が貸方残高になっていないか

## 手順

1. 上記6カテゴリそれぞれについて検出
2. 各項目に重大度（critical / warning / info）を付与
3. 結果を `data/periods/YYYY-MM/closing_checks.json` に保存:
   ```json
   {
     "period": "YYYY-MM",
     "checked_at": "ISO日時",
     "items": [
       {
         "id": "chk_001",
         "category": "deposit_diff",
         "severity": "critical",
         "title": "三菱UFJ銀行 月末残高差異 ¥12,300",
         "detail": "...",
         "suggested_action": "...",
         "status": "open"
       }
     ]
   }
   ```
4. サマリー表示（critical / warning / info の件数）
5. `closing-check.html` をブラウザで開けば確認できる旨を案内
6. 監査ログに追記
