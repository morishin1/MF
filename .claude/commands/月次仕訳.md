引数の YYYY-MM 月の証憑から仕訳ドラフトを生成してください。

## 入力
- `data/evidence/YYYY-MM/invoice/` のPDF
- `data/evidence/YYYY-MM/receipt/` の画像
- `data/evidence/YYYY-MM/bank/` のCSV/明細
- `data/evidence/YYYY-MM/card/` のCSV
- `data/master/accounts.json` の勘定科目マスタ
- `data/master/partners.json` の取引先マスタ
- `data/templates/journal_patterns.json` の過去パターン
- `CLAUDE.md` の自社勘定科目ルール

## 手順

1. **証憑インデックスの更新**
   - `data/evidence/YYYY-MM/_index.json` を読み込む（無ければ空で開始）
   - `invoice/`, `receipt/` 配下の各ファイルについて、Read tool でPDFや画像のテキストを抽出
   - 既に `_index.json` に SHA256 が記録されているファイルはスキップ
   - 新規ファイルは `{ filename, type, sha256, uploaded_at, ocr_text, ocr_amount, ocr_partner, ocr_date, linked_draft_id: null }` を追記

2. **仕訳ドラフト生成**
   - 各証憑について、以下の順で仕訳を推論:
     a. `journal_patterns.json` の `matcher` にマッチすれば、そのパターンを採用（`confidence: high`、`ai_reason: "パターン {key} に一致"`）
     b. マッチしない場合、`CLAUDE.md` の勘定科目ルールと勘定科目マスタを参照して推論（`confidence: mid` or `low`）
     c. 金額50万円超は必ず `confidence: low`（CLAUDE.mdの安全装置）
     d. `draft_id = drf_{YYYY-MM}_{連番4桁}` を採番
   - 銀行/カードCSVの行は1行=1仕訳の方針で展開

3. **保存**
   - 結果を `data/periods/YYYY-MM/journals_draft.json` に書き込み
   - 既存ドラフトがある場合は `evidence_ref` で突合し、未送信のものは上書き、送信済みは保護
   - 各証憑の `_index.json` の `linked_draft_id` を更新

4. **サマリーを表示**
   - 生成件数、信頼度別件数、要レビュー件数（low/mid）
   - 次のアクション: `journal-approval.html` をブラウザで開いてレビュー → 承認後 `/仕訳投入 YYYY-MM`

5. **監査ログ**
   - `data/log/audit.jsonl` に `{ ts, action: "journal_draft", period: "YYYY-MM", count: N }` を追記
