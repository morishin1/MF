引数の YYYY-MM 月の残高試算表を MF から取得し保存してください。

## 手順

1. **取得**
   - MCPツール `mcp__mf-accounting__*` の残高試算表取得APIを呼ぶ
   - 期間: 当月の月初〜月末（例: 2026-04 なら 2026-04-01 〜 2026-04-30）
   - 比較用: 前月・前年同月も同時取得すると後段のレポートで便利

2. **保存**
   - `data/periods/YYYY-MM/trial_balance.json` に以下の形式で保存:
     ```json
     {
       "period": "YYYY-MM",
       "fetched_at": "ISO日時",
       "current": { /* MFレスポンスそのまま or 整形 */ },
       "previous_month": { ... },
       "previous_year_same_month": { ... }
     }
     ```

3. **サマリー表示**
   - 売上高、売上総利益、営業利益、経常利益、現金預金残高
   - 前月比・前年同月比

4. **次のアクション**
   - `report-generator.html` をブラウザで開いて可視化を確認
   - 必要に応じて `/月次締め YYYY-MM`、`/月次レポート YYYY-MM`

5. **監査ログ**
   - `data/log/audit.jsonl` に `{ ts, action: "trial_balance_fetch", period: "YYYY-MM" }` を追記
